## Featured Projects

### 🚗 Car Rental Platform
`NestJS` `React` `TypeScript` `PostgreSQL` `Docker`

Multi-role rental platform with five React portals — customer, owner, admin, agent and manager — on a single NestJS REST API. PostgreSQL is split into six module-owned schemas, with JWT authentication, role-based access control, KYC document uploads and an end-to-end smoke-test suite. Containerised for single-origin deployment with a health endpoint so a deploy never hangs on a starting database.

→ [tej89032704-ctrl/car-rental](https://github.com/tej89032704-ctrl/car-rental)

### 🛍️ Sitha Fashions — E-commerce Store and Admin Panel
`Node.js` `Express` `SQLite`

Online clothing store with 46 screens and 77 route handlers: catalogue, cart, wishlist, coupons, Razorpay checkout with server-side signature verification, order tracking and returns. The admin panel covers products and stock, orders, customers, staff accounts, coupons and review moderation. Secured with bcrypt password hashing, JWT sessions in httpOnly cookies, CSRF tokens on every POST and per-IP rate limiting; 8 automated tests pass on Node's test runner.

→ [tej89032704-ctrl/sitha-fashions](https://github.com/tej89032704-ctrl/sitha-fashions)
